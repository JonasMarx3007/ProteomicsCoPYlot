Viewer projects live in this folder, one subfolder per project:

  viewer_data/<ProjectName>/viewer_config.json   (plus that project's data files)

Private, local-only projects go under viewer_data/local/<ProjectName>/, which
Git ignores. HEK293/ is the shipped example; its viewer_config.json shows the
keys a project uses. A data file key set to "none" (or left empty) means that
dataset is not provided, and the pages that need it stay switched off.

This file keeps the folder present in a fresh checkout.
See docs/INSTALLATION.md ("Viewer portal") for serving viewer projects.
